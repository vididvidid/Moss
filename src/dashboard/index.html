Moss
Moss is switched off. No script runs on any page or in the background until you switch it back on (the switch at the top right, or in the toolbar popup). Each script keeps its own Enabled setting.
User scripts are switched off. Chrome only runs user scripts when you allow it: open Moss's extension details and turn on Allow User Scripts (on Chrome before 138, turn on Developer mode instead).

Moss in five minutes


      
A script

      
// ==Moss==
// name:       Hide comments
// match:      https://news.example.com/*
// use:
//   - moss/dom/wait as wait
//   - moss/ui/toast as toast
// ==/Moss==

/*
 * hide(el) — remove one comment section
 */
function hide(el) {
    el.remove();
}

wait.observe('.comments', hide);
toast('Comments hidden');

      
Everything a script needs comes from the header. Moss works out which runtime features and modules to include,
        and nothing else gets injected. The Bundle tab shows what was included and why.


      
Two formats: .moss and userscripts

      
Moss has its own format, .moss, and also takes Tampermonkey and Violentmonkey userscripts exactly as they are.
        Both use the same keys and run the same way. New scripts you make in Moss use .moss
        (change it in Settings → New scripts).

      

        
.moss// ==Moss== … // ==/Moss==, one key: value per line. A key with
          several values can list them as - item lines under key:, and # … lines are notes.
          Runs in strict mode unless it says strict: off.

        
userscript// ==UserScript== … // ==/UserScript== with // @key value lines.
          Install it from any .user.js link, a file or GitHub. Runs in sloppy mode unless it says @strict.

      

      
The ⇄ button in the editor rewrites a header in the other format. It keeps every line, and the script behaves the same
        (strict mode included). Use it before you share a script with someone on Tampermonkey or Violentmonkey.
        Download saves a script as .moss or .user.js, and Settings → Backup can download every script as a zip.


      
Three sandboxes: @sandbox

      

        
isolatedThe default. Runs in a private world on the page: it sees the DOM but not the page's JavaScript. All GM APIs are available, and moss.chrome if granted.

        
pageRuns as the page's own JavaScript (aliases: none, raw, or Tampermonkey's @grant none). Can patch window.fetch and read page globals through unsafeWindow, and still use every GM API: Moss runs a small relay beside it in the sandbox.

        
extensionNo page at all: a background script with browser APIs (aliases: native, background). Use it for tools such as clearing history, managing tabs or bookmarks. Add // @grant chrome.history (or any namespace) and call await moss.chrome.history.search({ text: '' }) or moss.chrome.history.onVisited.addListener(fn).

      


      
Header keys

      

        
@match / @exclude-matchChrome match patterns: https://*.site.com/*

        
@include / @excludeGlobs (*) or /regex/

        
@run-atdocument-start · document-end · document-idle · context-menu (runs when picked from the right-click menu; Chrome 135+)

        
@noframesTop frame only

        
@inject-intoViolentmonkey's page / content / auto: the same as @sandbox page / isolated

        
@updateURL / @downloadURLA script that wasn't imported from a link updates from these when its @version goes up

        
@use path [as name]Bundle a module; as name makes it a variable

        
@require urlRemote library, downloaded once and cached. Add #sha256=… to check its hash

        
@resource name urlA file for GM_getResourceText(name) / GM_getResourceURL(name), downloaded once and bundled

        
@grantGM_xmlhttpRequest, GM_download, GM_cookie, window.close, window.focus, window.onurlchange, chrome.<namespace>

        
@connect hostHosts GM_xmlhttpRequest may reach (export → host permissions)

        
@folder a/bWhere the script sits in the sidebar

        
@inject rawNo wrapper: your code exactly as written (Tampermonkey's @unwrap does the same)

        
@strictRun the script in strict mode (recommended): silent mistakes, like assigning to a misspelled variable, become errors

      


      
APIs

      
GM_getValue/setValue/deleteValue/listValues · GM_getValues/setValues/deleteValues · GM_addValueChangeListener · GM_addStyle · GM_addElement ·
        GM_xmlhttpRequest · GM_notification · GM_registerMenuCommand (in the toolbar popup and the right-click menu) ·
        GM_openInTab · GM_setClipboard · GM_download · GM_getResourceText/URL · GM_getTab/saveTab/getTabs ·
        GM_cookie · GM_audio (mute the tab, follow its sound) · window.onurlchange · GM_info · GM.* promise versions ·
        moss.chrome · require(). Top-level await works.


      
Modules

      
Built-in: moss/ui (or its parts moss/ui/toast, panel, modal, fab,
        form, settings, button, core) and moss/dom
        (query, wait, url, util). Your own modules use folder paths such as
        utils/text and CommonJS style (exports.x = …). They receive api, the calling
        script's GM functions. Writing api['GM_getValue'] in quotes means "use it only if the script already has it",
        so the feature isn't pulled into the bundle. To change a built-in, open it and click Override built-in.


      
Strict mode

      
New scripts start with // @strict in the header, which runs them in JavaScript's strict mode. You can
        also turn it on per script (Options tab) or for everything (Settings → Runtime). Moss's own code always runs strict,
        but it never forces strict mode on scripts that don't ask for it.


      
Import & updates

      
Import… takes a GitHub file, folder or repository link (pick which scripts to bring in), a gist, or any URL.
        An imported script keeps its source. Click ↻ Update to pull the latest version, or turn on auto-update in its
        Options tab and choose how often Moss checks. If you edited a script in Moss, auto-update leaves it alone unless
        you allow overwriting in Settings. For private repos, add a GitHub token in Settings.


      
Export

      
Export as extension builds a Manifest V3 extension from one script and downloads it as a zip. It contains only the
        runtime pieces, background code, permissions and popup the script actually uses. You can review and edit every one
        of them before downloading.


      
Editor

      
The code is coloured as you type (Settings → Editor turns it off). Format (or Alt+Shift+F) re-indents the code and tidies
        the spaces in each line. It never joins or splits lines, and leaves strings, regexes and comments as written.
        case lines sit at the level of their switch, C style. Settings → Editor can format on every save.


      
Editor shortcuts

      
Defaults follow Tampermonkey's key map. Change them in Settings → Editor → Custom shortcuts with lines such as
        Ctrl-Shift-K = delete_line, or Ctrl-R = none to give a key back to the browser.
